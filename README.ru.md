# ClipVault

**ClipVault** — локальный менеджер истории буфера обмена для Windows на Tauri 2, React, TypeScript, Rust и SQLite. По умолчанию интерфейс на русском; язык можно переключить на английский.

## Текущий статус

Это ранняя рабочая основа, а не готовый к выпуску продукт. Событийный обработчик Windows сохраняет текст, растровые изображения и списки файлов; эти типы можно восстановить в буфере. Реализованы история, поиск, фильтры, избранное, сниппеты, настройки, исключения по имени процесса, системный трей, автозапуск и глобальные сочетания клавиш. Пути приложений-источников в карточках сокращены до имени; отдельная кнопка копирует полный путь. Release-сборка запускается без окна консоли. При наличии специального формата Windows `ExcludeClipboardContentFromMonitorProcessing` запись пропускается. Автоматическая вставка, полноценное управление будущими миграциями, подпись релизов и полная проверка приложения в работе пока не готовы. Не используйте текущую версию как средство защиты секретов.

Приложение задумано для работы без сети; история хранится в SQLite. Нет учётных записей и телеметрии. Для интерфейса используются системные шрифты.

## Разработка

Нужны Node.js 20+, Rust stable с MSVC target, Microsoft C++ Build Tools и WebView2 Runtime. В Windows:

```powershell
npm install
npm run tauri dev
```

Сборка интерфейса: `npm run build`.

Сборка установщиков NSIS и MSI: `npm run tauri build`. Установщики, собранные в этой рабочей копии (без подписи): `src-tauri/target/release/bundle/nsis/ClipVault_0.1.0_x64-setup.exe` и `src-tauri/target/release/bundle/msi/ClipVault_0.1.0_x64_en-US.msi`. GitHub Actions собирает оба пакета и прикрепляет их к опубликованному релизу.

## Данные и приватность

База SQLite находится в пользовательской папке данных приложения. Права администратора не запрашиваются. Скопированный текст может содержать секреты; при работе с ними приостановите мониторинг или закройте ClipVault. База пока не шифруется. Лимиты истории применяются при сохранении настроек.

`Ctrl+Shift+V` открывает окно истории. Если сочетание уже занято другой программой, ClipVault пытается использовать `Ctrl+Alt+V`; меню в системном трее остаётся доступно. Выбор записи восстанавливает содержимое в буфер, но не имитирует нажатие Ctrl+V.
